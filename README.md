# Mini-Project

Esse projeto analisa diferentes implementações de Normalizing Flows e seus trade-offs. Os modelos utilizados são encontrados em mini-project-1/src/models e suas análises estão em mini-project-1/notebooks.

## Setup
O projeto permite execução em GPU para isso siga as instruções de configuração dos drivers da sua placa.

Recomenda-se o uso de um virtual environment do python para gerenciamento das dependências. Após criá-lo, basta rodar o comando abaixo para instalar as dependências necessárias:

```shell
pip install -r mini-project-1/requirements.txt
```

## Execução

Basta rodar os notebooks para reproduzir as análises.
